# Satoshi — font ufficiale ARPHE

Satoshi è il carattere sans ufficiale per testo, etichette e bottoni.

È gratuito per uso personale e commerciale, ma **non è open source**. Indian Type Foundry lo
distribuisce tramite Fontshare sotto ITF Free Font License. La licenza non consente di copiare i
file del font in una repository pubblica o di passarli a un altro utilizzatore.

## Installazione corretta

1. Aprire <https://www.fontshare.com/fonts/satoshi>.
2. Leggere e accettare la licenza: <https://www.fontshare.com/licenses/itf-ffl>.
3. Scaricare la famiglia direttamente da Fontshare.
4. Installare almeno Regular 400, Medium 500 e Bold 700.

Su Canva Pro o Teams: **Brand > Font > Carica un font**, quindi caricare i file scaricati dal
proprio account. Ogni persona o postazione deve effettuare direttamente questo passaggio.

## Uso sul Web

Per documenti HTML online si può usare il foglio stile ufficiale Fontshare:

```html
<link rel="stylesheet"
  href="https://api.fontshare.com/v2/css?f[]=satoshi@400,500,700&display=swap">
```

I template di questa repository funzionano anche offline con il fallback tecnico `DM Sans`,
Arial o sans-serif. Il fallback garantisce l'apertura, ma non sostituisce Satoshi nelle consegne
grafiche definitive.
