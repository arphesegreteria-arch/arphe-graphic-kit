# Uso del Graphic Kit con un'AI

Allega `brand-guidelines/ISTRUZIONI-PER-AI.md` alla conversazione e chiedi un file HTML/CSS alla
dimensione desiderata. Per ottenere colori e testo editabile non chiedere all'AI di generare
l'intera grafica come immagine.

Esempio:

> Seguendo le istruzioni di marca allegate, crea un post HTML 1080×1350 informativo sul servizio
> di dermatologia. Usa un titolo breve, una descrizione e un solo bottone. Non generare o
> ridisegnare il logo; lascia un punto chiaramente indicato dove inserirò il file ufficiale.

Usa la generazione immagini solo per fotografie senza testo, da convertire in bianco e nero prima
dell'impaginazione. Il logo deve sempre provenire da `logos/`.
